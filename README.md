## How I Work

```text
Understand the problem → Build a focused MVP → Test & verify → Ship → Improve
```

사용자가 겪는 문제를 먼저 정의하고, 실제로 작동하는 작은 제품부터 만듭니다.  
자동화의 속도만큼 **검증 가능성, 비용, 보안, 장기 유지보수성**을 중요하게 생각합니다.
